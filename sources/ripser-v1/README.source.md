# TamerOp source used by both Rips comparisons

These package files are the unchanged frozen source used in the Ripser.py
study of 5 October 2026 and the C++ Ripser study of 6 October 2026.
`SOURCE_SHA256.json` records the original digest of each source, project and
manifest file. Both studies' sealed evidence contains the same source digest
map. The additional license and this provenance note do not replace that map.

The package is distributed under the included MIT license. New measurements
using this snapshot describe this snapshot; the current TamerOp library is a
separate project.
